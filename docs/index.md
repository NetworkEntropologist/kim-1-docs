# KIM-1 Documentation

This is a fully indexed and searchable recreating of the original documentation for the KIM-1 by MOS Technologies, built by taking the original documentation from the Internet Archive, performing a full OCR on these, and finally extracting the text and images and compiling these into here.

Please note that while this is an ongoing project, it is not currently open to contributors. At least not yet. This will however change in the future, so please keep an eye on this. For more information, please look at the <a href="https://github.com/NetworkEntropologist/kim-1-docs" target="_blank">GitHub Repo</a>.

# Contents

The contents of this site is broken down into sections, each section covering a single manual.
